A production-oriented machine learning platform built on Google Cloud.

This project documents my journey from ML fundamentals to\
production ML systems and MLOps.

- Build practical understanding of machine learning

- Deploy and monitor production ML models
- Implement ML CI/CD and automated retraining
- Explore GenAI and RAG
- Compare managed ML services with Kubernetes-based approaches
